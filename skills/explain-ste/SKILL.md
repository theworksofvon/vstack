---

Needs nothing beyond this repo. Output is prose in the chat; no file.

The argument is an optional dial followed by the topic. `80% how DNS
resolves a name` relaxes the rules to 80%; a bare topic means 100%.

1. Run the brief from [`../explain/SKILL.md`](../explain/SKILL.md): one
   question, three to five ideas, a slug. The slug is unused here but the
   discipline is the same.
2. Read [`../explain/STE100.md`](../explain/STE100.md) and note which rule
   groups the dial selects.
3. Write one paragraph per idea, in the order a reader needs them. The first
   sentence of the whole answer states the answer to the question. Every
   paragraph after the first builds on a term the previous one defined.
4. Run the self-check at the end of the digest. Deliver only after a clean
   pass.
5. Close with one line naming the dial used, so the reader knows how to ask
   for looser or stricter next time.
